# Application updates

Help → Check for updates performs a manual check of the public stable release
channel. Nothing contacts the channel during startup. Metadata must identify the
expected repository, version, platform, installer and matching installed-test
identity; the release checksum must agree. Downloads use HTTPS, bounded reads,
size checks and SHA-256 verification before publishing a new staged file in the
application cache. Cancellation or corruption leaves no published installer.

The app offers to reveal the downloaded installer folder and close after pending
work and unsaved edits are resolved. Run the installer after Scout closes. It does
not replace a running app, execute downloaded helpers or delete the previous
installer/model pack. Linux uses the downloaded Debian package; Windows uses its
per-user setup program; macOS uses its disk image.

The channel consumes `release-manifest.json` and `SHA256SUMS.txt` generated by the
candidate-promotion workflow. Older releases without those files cannot be offered
through this updater. Real hosted release checks, redirects and native upgrades
remain to be validated. HTTPS plus checksums provides channel integrity; it does
not substitute for publisher signing. See [installation](installation.md) for
platform security prompts and [future path](future-path.md) for release gates.

GitHub's [release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)
provides the stable release metadata. No credentials or private repository tokens
are transmitted by the app updater.
